# ⏳ 13. Belt / ESP32 Commands

**Planned — NOT fully connected yet**

We established an important requirement:

The belt should **NOT** receive a command on every GPS/compass update.

Instead:

```text

```

The belt receives:

```text

```

```text

       ↓

```

the belt receives:

```text
FORWARD_RIGHT
```

once.

So the eventual architecture is:

```text

     ↓
Confirmed Direction
     ↓
Belt Command Layer
     ↓
BLE
     ↓
ESP32
     ↓
Motor
```

And the ESP32 project remains based on the architecture we've already established.
